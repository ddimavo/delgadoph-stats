# Delgado PH Stats

Клиентское веб-приложение (SPA, работает и как PWA) со статистикой форума, публикациями по разделам, планом, хранилищем файлов и выплатами.
Интерфейс — Preact в браузере без сборки; сервер — тонкий JSON-API (Fastify + SQLite).

## Структура сайта
| Раздел | Что внутри |
|---|---|
| Обзор | KPI с динамикой, публикации и форум по неделям, тепловая карта активности, оценки качества, лучшие сотрудники, топ форума |
| Скриншот-ситуации, Радиоэфиры, Мероприятия, Прочее | **Заполняются автоматически**: публикация из плана со статусом «Опубликовано» и видом раздела сразу появляется в нём. В разделе: статистика, график, оценки, лидеры, карточки со скриншотом, описанием и ссылкой |
| Объявления | Правки объявлений вводятся вручную по неделям; динамика и лидеры |
| Статистика форума | Темы форума: посты за 24 ч / 7 / 30 дней, авторы, активность 0–100, пользователи |
| План публикаций | Доска (перетаскивание карточек), список, календарь; тип, оценка 1–5 ★, краткое описание, ссылка, вложения |
| Хранилище | Папки, drag-and-drop загрузка, предпросмотр скриншотов |
| Выплаты (admin) | Недельный расчёт по расценкам и лимитам, расценки редактируются, выгрузка xlsx |
| Доступ (admin) | Список ников и роли admin / editor / viewer |

Вход по нику без пароля, но только для ников из списка.

## Запуск
```bash
npm install
ADMIN_NICK=Brianna_Delgado npm start     # http://localhost:3000
npm test
```
Docker: `docker build -t delgadoph-stats . && docker run -d -p 3000:3000 -v stats-data:/data -e ADMIN_NICK=Brianna_Delgado delgadoph-stats`

Переменные: `PORT`, `DATA_DIR` (БД и файлы), `ADMIN_NICK`, `TZ_NAME` (по умолчанию Europe/Moscow), `MAX_UPLOAD_MB` (50), `SECURE_COOKIE=1` (если сайт под HTTPS), `W_WEEK`, `W_MONTH`, `W_AUTHORS`.
Старые базы мигрируют автоматически (темы форума теперь `topics`).

## Выплаты
Считаются по публикациям в статусе «Опубликовано» с видом, ответственным (ник) и оценкой; неделя (пн–вс) определяется датой публикации.

| Вид | Расценка по умолчанию | Лимит в неделю |
|---|---|---|
| Скриншот-ситуация | 1★ 0 · 2★ 25 000 · 3★ 50 000 · 4★ 75 000 · 5★ 100 000 $ | 300 000 $ |
| Объявления (правки вводятся вручную) | 500 $ за штуку, оплачивается не более 300; бонус 50 000 $ раз в неделю, если правок больше 100 | — |
| Мероприятие | 1★ 100 000 … 5★ 500 000 $ или сумма вручную (100 000–500 000 $) | 1 000 000 $ |
| Радиоэфир | 30 000 $ за эфир от 3★ | 500 000 $ |

Всё меняется в интерфейсе; расчёт идёт по текущим расценкам, в том числе для прошлых недель. Бонус за объявления считается по фактическому числу правок.

## Ввод постов форума
Форум закрыт защитой от ботов, поэтому данные вносятся вручную: на странице темы вставьте строки `ДД.ММ.ГГГГ ЧЧ:ММ Ник` (время по поясу `TZ_NAME`).
Повторно вставленные посты пропускаются; при ошибке в любой строке не сохраняется ничего.

## Устройство
- `src/` — сервер: `routes/` (API), `stats.js` / `analytics.js` (расчёты), `payouts.js`, `export.js` (xlsx), `db.js` (схема и миграции).
- `public/` — клиент: `js/app.js` (роутер, каркас), `js/ui.js` (компоненты и графики), `js/views/*` (страницы), `vendor/` (Preact + htm, без CDN).
- Защита API: cookie-сессия (HttpOnly, SameSite=Lax) + заголовок `X-Requested-With` на изменяющих запросах; все данные экранируются шаблонизатором.

## Безопасность
Вход без пароля означает, что любой, кто знает ник из списка, может войти под ним. Держите сайт за закрытым адресом/VPN или HTTP-авторизацией на reverse proxy и не вносите в список лишних ников.
