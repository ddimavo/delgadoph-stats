# Delgado PH Stats

Сайт со статистикой разделов форума (темы раздела «Новостное агентство»), планом публикаций и файловым хранилищем.

## Возможности
- Обзор: посты всего / за 24 ч / 7 д / 30 д по каждому разделу, график по дням и по часам, авторы, последние посты.
- Показатель активности раздела (0–100): `0.5 × посты за 7 дней + 0.3 × посты за 30 дней + 2 × уникальные авторы за 30 дней`, нормируется по самому активному разделу. Веса меняются переменными `W_WEEK`, `W_MONTH`, `W_AUTHORS`. Первый пост темы ответом не считается.
- Рейтинг пользователей за 7 / 30 дней / всё время.
- План публикаций: дата, статус, тип, раздел, ответственный, краткое описание (до 500 символов), оценка качества 1–5 звёзд, вложения.
- Выплаты (только admin): расценки и лимиты редактируются на странице «Выплаты → Расценки», расчёт по неделям (пн–вс), см. ниже.
- Выгрузка в xlsx (`/export.xlsx`): разделы, пользователи (7/30 дней/всё время), все посты, план публикаций; для admin ещё выплаты недели и детализация.
- Хранилище: дерево папок, загрузка скриншотов и файлов (вложения публикаций попадают в `Публикации/#id название`).
- Вход по нику без пароля, но только для ников из списка (роли: admin / editor / viewer).

## Запуск
```bash
npm install
ADMIN_NICK=Brianna_Delgado npm start     # http://localhost:3000
npm test
```
Docker: `docker build -t delgadoph-stats . && docker run -d -p 3000:3000 -v stats-data:/data -e ADMIN_NICK=Brianna_Delgado delgadoph-stats`

Переменные: `PORT`, `DATA_DIR` (БД и файлы), `ADMIN_NICK`, `TZ_NAME` (по умолчанию Europe/Moscow), `MAX_UPLOAD_MB` (50), `SECURE_COOKIE=1` (если сайт под HTTPS), `W_WEEK`, `W_MONTH`, `W_AUTHORS`.

## Выплаты
Считаются по публикациям в статусе «Опубликовано» с типом, ответственным (ник сотрудника) и оценкой; неделя определяется датой публикации.

| Тип | Расценка по умолчанию | Лимит в неделю |
|---|---|---|
| Скриншот-ситуация | 1★ 0 · 2★ 25 000 · 3★ 50 000 · 4★ 75 000 · 5★ 100 000 $ | 300 000 $ |
| Объявления (правки вводятся вручную раз в неделю) | 500 $ за штуку, оплачивается не более 300; бонус 50 000 $ один раз, если правок больше 100 | — |
| Мероприятие | 1★ 100 000 … 5★ 500 000 $ или сумма вручную (100 000–500 000 $) | 1 000 000 $ |
| Радиоэфир | 30 000 $ за эфир от 3★ | 500 000 $ |

Всё это — значения по умолчанию, меняются в интерфейсе. Расчёт всегда идёт по текущим расценкам, в том числе для прошлых недель.
Бонус за объявления считается по фактическому числу правок, а не по оплаченному (до лимита 300).

## Как вносить данные
Данные вносятся вручную, форум сайт не опрашивает.
1. На «Обзоре» добавьте раздел (название, ссылка на тему — по желанию).
2. На странице раздела вставьте посты в поле «Внести посты»: одна строка — один пост, формат `ДД.ММ.ГГГГ ЧЧ:ММ Ник`
   (подходит и `ГГГГ-ММ-ДД ЧЧ:ММ Ник`). Время считается в поясе `TZ_NAME`.
3. Раз в неделю вносите новые посты. Повторно вставленные посты пропускаются, так что можно вставлять с запасом.
   Если хотя бы одна строка некорректна, не сохраняется ничего, и сайт покажет, какая именно.
Ошибочный пост удаляется крестиком в списке последних постов.

## Безопасность
Вход без пароля означает, что любой, кто знает ник из списка, может войти под ним. Держите сайт за закрытым адресом/VPN или
HTTP-авторизацией на уровне reverse proxy и не вносите в список лишних ников.
